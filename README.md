# 📌 TimeBox - Gestor de Tareas

TimeBox es una aplicación diseñada para la gestión eficiente de tareas, permitiendo a los usuarios registrar, modificar y eliminar actividades dentro de un calendario. Además, incluye funcionalidades como autenticación de usuarios, notificaciones y un historial de modificaciones.

## 🚀 Características

- ✅ **Autenticación de usuarios** (Registro, inicio y cierre de sesión).
- 🗂 **Gestión de tareas** (Crear, modificar, eliminar y visualizar tareas).
- 📅 **dashboard visual** permite una visualizacion preliminal de las tareas del dia
- 🔔 **Notificaciones por WhatsApp** para recordar un evento con una notificacion enviada
- 📜 **Historial de tareas completadas** de las tareas registradas.
- 🎨 **Personalización de la aplicación** según las preferencias del usuario cambio de tema de claro a oscuro.

## 🛠 Tecnologías Utilizadas

- **Lenguaje:** Python
- **Base de Datos:** JSON (almacenamiento simple)

1. **Registro** con nombre de usuario, numero de telefono, contraseña
2. **Inicio de Sesion** con nombre de usuario, contraseña
3. **Recuperar contraseña** con nombre de usuario, asignacion de nueva contraseña , codigo secreto(0626)
